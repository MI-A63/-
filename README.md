Программа определяет операционную систему, на которой она запущена, собирает основные параметры операционной системы и компьютера, после чего сохраняет полученную информацию в JSON-файл.
Скрипт предназначен для работы в следующих операционных системах:

Windows
Linux
macOS

Запуск программы: python OC.py

После выполнения программы в текущей директории создаётся файл: os_info.json

Программа собирает следующие данные:

название ОС
версия выпуска (release)
версия системы (version)
архитектура процессора
версия Python
реализация Python
имя компьютера (hostname)
информация о процессоре
имя текущего пользователя
количество доступных процессорных ядер/потоков
текущая рабочая директория
абсолютный путь к скрипту
время сбора информации

В работе используются только стандартные модули Python:

platform — получение информации об операционной системе, версии и аппаратной платформе
os — получение количества процессоров, текущей директории и других параметров окружения
socket — получение имени компьютера
sys — стандартный модуль Python для работы с информацией о среде выполнения
json — сохранение собранной информации в JSON
datetime — получение времени сбора данных
getpass — получение имени текущего пользователя

Внешние библиотеки не использовались, поскольку необходимая для выполнения задания информация доступна через стандартную библиотеку Python. Это также позволяет запускать программу без установки дополнительных пакетов.

Программа не использует системные утилиты операционных систем (uname, systeminfo, lsb_release и другие). Сбор информации выполняется средствами стандартной библиотеки Python.

После запуска создаётся JSON-файл с собранной информацией: os_info.json
